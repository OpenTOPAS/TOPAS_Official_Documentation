Installation
============

Installation instructions for the latest TOPAS version (OpenTOPAS v4.3.0) are provided in the QuickStart guides on the GitHub_ page. Alternatively, see the quickStart guide appropriate to your operating system in the panel on the left.

Core OpenTOPAS v4.3.0 supports Geant4 11.3.2 and 11.4.2. The native guides
below demonstrate 11.4.2; select 11.3.2 for public TOPAS-nBio. See :ref:`version`
for compatibility and dataset requirements, or :ref:`container_images` for
Docker and Apptainer installation.
